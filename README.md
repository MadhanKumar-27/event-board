# local community event board

## problem
small clibs and neighborhoods lack a simple central place for meetups.

## features planned
* post events
* filter by category
* RSVP
* persistent storage

##tech used
* HTML
* CSS (Grid/flexbox)
* javascript
* localstorage

## MVP features
1. a user can post an event with a validated form
2. all events are displayed as cards
3. events can be filtered by sports,study, or tech
4. a user can RSVP to an event
5. everything persists after a page refresh
